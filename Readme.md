# DesignX | IIT Bhilai

This is the official submission for the OpenLake HelloWorld 24-hour Hackathon. 

**Live Demo:** [https://designx-helloworld.vercel.app/](https://designx-helloworld.vercel.app/)

## Tech Stack & Credits
* **Core:** HTML5, CSS3, Vanilla JavaScript, GSAP Animations
* **Animation Engine:** [GSAP (GreenSock)](https://greensock.com/) & ScrollTrigger for cinematic scroll-jacking and parallax effects.
* **Typography:** Inter, Space Grotesk, and Space Mono via Google Fonts.
* **Assets:** Local club photos and standard audio/GIF assets.
* **Deployment:** Vercel
* **AI:** Used a bit of gemini for advice on color schemes and bug fixes regarding mobile compatibility.
